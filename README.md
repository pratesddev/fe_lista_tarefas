# Lista de Tarefas

**Aplicação web simples para adicionar tarefas e armazená-las com JavaScript.**

---

## 📖 Sobre

O Lista de Tarefas é um projeto de estudo desenvolvido com HTML e JavaScript. Ele permite cadastrar tarefas, exibí-las dinamicamente na página e mantê-las no navegador por meio da API `localStorage`.

A implementação utiliza manipulação do DOM, eventos, arrays e armazenamento local.

---

## ✨ Funcionalidades

- [x] Campo para digitar uma nova tarefa
- [x] Botão para registrar tarefas
- [x] Exibição dinâmica dos itens cadastrados
- [x] Validação de campo vazio
- [x] Persistência das tarefas com `localStorage`
- [x] Recuperação das tarefas ao recarregar a página

---

## 🛠 Tecnologias

- HTML5
- JavaScript

---

## 🚀 Começando

### Pré-requisitos

- Navegador web atualizado

### Executando

Não há dependências ou processo de instalação.

1. Faça o download ou clone deste repositório.
2. Abra o arquivo `index.html` diretamente no navegador.

Também é possível executar o projeto com uma extensão como Live Server.

---

## 💻 Uso

Digite uma tarefa no campo de texto e clique em **Registrar**. Ao atualizar ou reabrir a página pelo mesmo navegador e origem, as tarefas persistidas serão carregadas novamente.
