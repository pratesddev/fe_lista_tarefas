## 📋 Sobre o projeto

Aplicação que mescla HTML e JS para criação de uma lista de tarefas, utilizando recursos de localStorage.

### Objetivo

O principal objetivo deste projeto foi aprender o básico de manipulação de página web com JavaScript e também a utilização de recursos básicos como o local storage para persistência de dados. Além disso também foi aprendido sobre formas de listar e deletar itens de uma lista.
